# Pomodoro Timer

A simple Windows desktop pomodoro timer built with Python and Tkinter.

## Project Goal

This project is a beginner-friendly practice project.

The target is to build a local Windows timer app step by step, starting from the most basic version:
- show a window
- display 25:00
- click Start to count down every second

More features will be added later:
- pause
- reset
- work / break mode
- local stats
- Windows notifications
- packaging to exe

## Tech Stack

- Python
- Tkinter
- GitHub repository as the source of truth
- Codex web for code generation and editing
- Local Windows machine for testing
