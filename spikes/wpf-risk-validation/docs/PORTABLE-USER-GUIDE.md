# Pomodoro Timer 2.0 Portable 使用说明

## 这是什么

这是一个 Windows 计时器技术预览，当前提供 **30 秒验证计时**，不是完整的番茄工作法正式产品。可以开始、暂停、继续计时，隐藏到系统托盘，并尝试发送测试通知或计时完成通知；没有历史统计、周期管理或完整设置页面。通知提交成功不保证 Windows 会显示横幅。

目标桌面是 **Windows 11 25H2 x64（26200.x）**。真实桌面启动、托盘、通知和搬迁行为仍待验证，本说明不是已通过桌面验收的保证。

## 解压和启动

1. 从可信来源取得 `PomodoroTimer-Portable-Windows-x64.zip`。
2. 将 ZIP **完整解压**到当前用户可写的本地文件夹。保留其中整个 `PomodoroTimer` 文件夹和所有 DLL、资源文件，不要只复制 EXE。
3. 打开解压后的 `PomodoroTimer` 文件夹，双击 `PomodoroTimer.exe`。不要在压缩包内直接运行。
4. 点击“开始 (Start)”进行 30 秒计时；“暂停 / 继续”控制同一段计时。

这是 Portable 目录版，**无需 Setup.exe、MSI 或管理员权限**，不提供安装器。发布目录包含应用运行依赖，不要求用户安装开发 SDK。

## 为什么目录必须可写

应用将数据和日志保存在 EXE 所在目录，不回退到 AppData，也不会为写入请求管理员权限。不要放在 Program Files、Windows 系统目录或其他当前用户不能写入的位置。

正常启动会创建：

- `Data`：`settings.json` 保存设置，`state.json` 保存计时状态；保存过程中可能有备份文件。重启时，原先运行中的计时按保存的剩余时间以暂停状态恢复，不把退出期间时间算进计时；需要手动继续。
- `Logs`：诊断日志，名称类似 `pomodoro-日期-序号.log`，供排查启动、数据保存和通知问题。

不要运行中手动编辑、覆盖或删除这些文件。Data 不可写会明确报错；Logs 无法写入会警告，但不会因此停止计时。日志可能因容量和保留期限被清理，不应当作永久历史记录。

## 隐藏、打开和正常退出

关闭窗口或点击“隐藏到托盘”只隐藏窗口，**不会退出，计时仍可继续**。双击托盘图标，或右键选择“打开 (Open)”可打开窗口；图标也可能在 Windows 的隐藏图标区域。

需要完全退出时，在托盘图标上右键选择 **“退出 (Exit)”**，等待进程结束后再备份、搬迁或删除文件夹。不要把强制结束进程当作正常退出；最近尚未保存的状态可能丢失。

## 备份和搬迁

先正常退出，然后复制或备份 **整个 `PomodoroTimer` 文件夹**，包括程序、DLL、资源、Data 和 Logs。恢复时同样恢复整个文件夹，勿将运行中的旧文件夹与新文件混合覆盖。

搬迁前保留完整备份，退出所有实例，再把整个文件夹移到另一当前用户可写的本地位置，从新位置启动。**路径变更后的通知注册、旧通知点击启动以及注册清理尚未通过真实 Windows 验证。** 普通退出并不意味着永久清除 Windows 通知注册；旧通知可能仍指向旧路径。不要把复制文件夹理解为通知身份已自动迁移或旧注册已清理。遇到通知问题，暂时保留原目录与备份，检查日志，不要自行编辑系统注册表。

本预览不承诺所有移动硬盘、网络盘、文件系统或断开设备场景受支持。建议使用稳定可写的本地磁盘，不要运行时拔盘、断开共享或搬迁目录。

## 常见问题和日志

- **打不开 / 提示缺少 DLL**：确认完整解压、所有依赖文件仍在同一目录，并使用目标 x64 Windows 平台。不要从任意网站补下载 DLL。
- **Data 目录不可写**：先退出，将整个文件夹移至当前用户可写位置，检查权限、磁盘空间以及 Data 是否被同名文件占用；不要通过以管理员运行来绕过目录选择问题。
- **没有窗口**：检查托盘及隐藏图标区域，双击图标打开。关闭窗口不等于退出。
- **通知不出现**：检查 Windows 通知设置、勿扰模式和窗口中的通知状态。发送成功仅表示提交；实际显示、点击激活及搬迁后的通知行为未验证。
- **保存或日志失败**：查看窗口诊断/启动错误提示，检查目录权限和可用空间。日志不可写时可能没有可用的日志文件。

查看日志：打开程序文件夹中的 `Logs`，用文本编辑器查看最新的 `pomodoro-日期-序号.log`。日志使用 UTC 时间，每行包含级别、事件、消息和可能的异常信息。求助时记录错误提示、发生时间、Windows 版本及相关日志；分享前检查并移除个人路径等信息。应用不自动上传日志。
