# UI Refresh 01

## Goal

Refresh the Tkinter interface with a bright, clean, cheerful visual style.

## Scope

This refresh includes:
- a light fresh window background
- a centered white content card with cleaner spacing
- larger, more playful timer text
- a more noticeable status label with stronger visual contrast
- distinct button colors for Start (green), Pause (orange), and Reset (light blue)
- status text colors for Idle (blue-gray), Running (green), and Paused (orange)

This refresh does not include:
- timer logic changes
- Start / Pause / Reset behavior changes
- break mode
- notifications
- local storage
- external dependencies

## Completion Criteria

The refresh is complete when:
1. `python main.py` starts successfully
2. the window has a light, fresh background and cleaner spacing
3. timer text is visibly larger and more lively
4. status label is clearly noticeable
5. status colors update correctly for Idle, Running, and Paused
6. Start / Pause / Reset buttons are clearly colored and easy to distinguish
7. existing timer behavior remains unchanged
